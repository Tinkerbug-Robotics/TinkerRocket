# L2 100mm Rolly Polly V — pre-flight CFD & roll PID tuning

The next vehicle in the Rolly Polly line: 4-inch (102 mm) fiberglass airframe on
AeroTech 38 mm J motors, four PETG fins on a printed boat-tail fin can, each fin
carrying a servo-driven trailing-edge tab on a spanwise torque rod. First flight is
**roll control only** (rate-null mode), same controller structure as the 67 mm testbed.

This folder is the pre-flight analysis: a 33-case OpenFOAM sweep of tab deflection
(−20°…+20°) at 40/80/120 m/s, the roll-plant model built from it, and the PID gains
derived for the first flight. Flight logs will join it after the rocket flies.

**Start with [`CFD_Report_100mm_Fin_Tab.html`](CFD_Report_100mm_Fin_Tab.html)** — it
contains the full methodology, figures, uncertainty discussion, and the firmware/sim
configuration blocks.

## Headline numbers

| Quantity | Value |
|---|---|
| Tab roll authority K<sub>t</sub> (per tab, about body axis) | 2.76 / 11.48 / 26.16 mN·m/deg at 40 / 80 / 120 m/s (R² ≈ 0.995) |
| Built-in trim asymmetry | ≈ 0.6° equivalent tab (offset scales with q) |
| Roll inertia I<sub>roll</sub> | 18.3 × 10⁻³ kg·m² (fin set 7.6 × 10⁻³, CAD volume integral) |
| Plant gain K<sub>plant</sub> at 50 m/s | ≈ 56 deg/s² per tab-deg (4 tabs common-mode) |
| **First-flight gains** (V<sub>ref</sub> = 50 m/s) | **KP = 0.224, KI = 0.134, KD = 0** — 2.0 Hz crossover, ≈ 64° phase margin |
| Motors | J435WS (V<sub>max</sub> ≈ 91 m/s), J570W (V<sub>max</sub> ≈ 119 m/s) |

Gain schedule, ±20° command clamp, 40 dps integral separation, and the 10 Hz D-filter
stay at their existing `config.h` values. Before flying: bench spin test to confirm tab
direction (`FIN_ROLL_REVERSE_MASK`) — CFD gives magnitude, mounting sets sign.

## Reproducing

The scripts are as-run copies from the local analysis directory
(`~/Documents/Hobbies/ModelRockets/CFD/100mm-L2-Rocket-Fin-Tab-Analysis/` — `run_sweep.sh`
carries that absolute path). Needs Docker (`opencfd/openfoam-default:2412`), python3 with
cadquery ≥ 2.7, numpy, matplotlib. ~3.5 h for the sweep on a 10-core M-series, two cases
at a time:

```bash
python3 build_geometry.py     # 11 deflected STLs from the STEP
bash run_sweep.sh             # 33 OpenFOAM cases
python3 postprocess_sweep.py  # Kt fits
python3 roll_inertia.py       # I_roll + damping
python3 generate_report.py    # the HTML report
```

## Provenance

CFD run 2026-08-09 (OpenFOAM v2412, Docker, ~272k cells/case, all mesh-quality checks
clean, zero failed cases). Motor data from thrustcurve.org. The moment arm assumes the
fin root plane sits 44 mm from the centerline (mid boat-tail); the ±7 mm extremes move
K<sub>t</sub> by ∓6% — inside the controller's margins either way.
