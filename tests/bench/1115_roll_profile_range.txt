# #1211 / #1115 — roll-profile waypoints are range-checked; a bad profile is
# REJECTED (never clamped) and the previous profile survives.  Merged d58e3a9b.
#
# Rig: V9 pair, S1 -> F (FLIGHT COMPUTER console — the [ROLL PROF] lines are FC-side).
# cmd 26 = RollProfileData, 76 bytes: [num_wp u8][pad 3][8 x {time f32, angle f32, mode u8}].
# NB the generated protocol reference omits the per-waypoint mode byte and so
# describes a 68-byte frame; the FC requires cfg_len >= sizeof(RollProfileData)
# = 76, and a short frame is silently ignored rather than rejected.
#
# Bounds under test (RollProfileGate.h): |angle| <= 720 deg, time in [0, 600] s,
# times non-decreasing, count <= 8 — each non-finite value caught by isfinite.
